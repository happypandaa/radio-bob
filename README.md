# Radio Bob

本机运行的个人 AI 电台：用自然语言选歌，听 Bob 的中文串词，也可以直接搜歌、管理待播队列、保存音乐品味。当前是个人使用版本，没有部署到公网。

## 平台受管 Node 试验

`server/managed.mjs` 和 `local-app.json` 支持平台从源码构建、安装和更新独立运行副本，由平台管理启动、停止、配置与私有数据目录。网页与后端由同实例代理连接；构建需要安装生产依赖。平台安装更新、真实语音和账号链路的验收范围见受管说明，自动化测试不代表所有线上服务与平台版本均已验证。

原 `npm run dev` / `npm start` 仍按下文独立运行，不读取实验清单。受管入口不加载原项目 `.env`、`.data` 或 `user/taste.md`；只有收到实例初始化后才打开平台注入的隔离目录。网易云 SDK 在同一 Node 进程调用，不启动第二个音乐 HTTP 服务；所有后端 HTTP 路由均需实例认证，不提供静态网页。

平台模式与浏览器独立模式均支持网易云扫码登录。点击右上角 LOGIN，在当前应用内用网易云音乐 App 扫码并确认；连接后显示 LINKED，可在同一弹窗退出。平台模式将登录会话单独保存在实例的 `APP_DATA_DIR/credentials/netease-session/` 私有目录，目录权限 0700、文件权限 0600，不写入业务数据库或页面响应。原独立版保留业务库 Cookie 存储兼容；两种模式的账号与数据互不迁移。

首次验证只用人工数据检查生命周期。2026-10-20 后续按用户授权，使用临时环境注入的 DeepSeek 凭据与全新数据目录，通过一次真实 `deepseek-flash` 节目生成、曲库匹配、浏览器试听和可匿名播放的完整音源样本；未配置 Fish。真实试用发现并修复了函数式 SDK 缺 xeapi 公钥导致的播放失败。浏览器使用一次性本机适配器，不代表平台正式代理或安装功能已交付，密钥未保存到项目。

使用边界见[受管试验使用说明](docs/MANAGED_USER_GUIDE.md)，协议和验证方式见[开发说明](docs/MANAGED_DEVELOPMENT.md)。

`local-app.json` 只需配置两把密钥：DeepSeek API Key（必填）和 Fish API Key（可选）。服务地址、模型和音色使用默认值；未填 Fish 密钥时仍可看文字串词和听音乐。清单只包含说明和官方帮助链接，不包含真实密钥。

平台使用时先关闭 Radio，在原生管理窗口通过“查看新版应用说明”或构建更新同步当前清单与资源，再保存密钥并重新打开。更新应保留同一实例的配置、密钥与业务数据；源码改动不会直接替换已安装的运行副本。

## 启动

需要 **Node.js 24 或更新版本**，以及所选 AI 服务的 API 凭据。Node 后端直接请求 AI 接口，无需安装或登录 Claude Code。

```sh
cd radio-bob
npm install
npm run dev
```

浏览器打开 [Radio Bob](http://localhost:8080)。启动命令同时管理两个本地服务：

- `8080`：Radio Bob 界面与应用服务。
- `3000`：社区网易云音乐接口服务；已运行时会复用。

两者默认只监听 `127.0.0.1`。关闭终端中的任务或按 `Ctrl+C` 停止本次启动的服务。

## 独立运行配置

浏览器独立运行时，只需在项目根目录 `.env` 填写两把密钥，修改后重启。已有文件直接编辑；新机器可从 `.env.example` 创建，避免覆盖已有密钥。

```dotenv
ANTHROPIC_API_KEY=你的DeepSeek密钥
FISH_API_KEY=你的Fish密钥
```

`ANTHROPIC_API_KEY` 是现有环境变量名，在本项目中填写 DeepSeek API Key。默认请求 `https://api.deepseek.com/anthropic`，模型为 `deepseek-flash`，开启思考，`max_tokens` 默认 16384，给思考内容留出余量，避免节目 JSON 被截断。Fish 使用 `s2.1-pro-free`，不指定音色 ID，由 Fish 提供默认音色。Fish 密钥可留空，仍能使用文字和音乐。密钥仅在 Node 后端使用，不填进浏览器页面。

运行端口仍默认为 `8080`，音乐接口为本机 `3000`。已有独立入口的高级环境变量兼容读取保留；如需采用上述默认值，可从旧 `.env` 移除自己曾填写的地址、模型和音色覆盖值。

状态检查只确认 API 配置有效，尚未发起模型请求时不代表已验证远端连通。生成过程处理接口拒绝、输出截断、限流、超时、响应过大与 JSON 校验失败。思考内容不会进入业务记录；歌曲与口播仅在完整通过校验后使用。暂停、继续、切歌等本地控制仍无需请求模型。

主持语音仅使用 Fish Audio。配置 API 密钥后可用默认音色生成口播；不填密钥或在界面关闭自动口播时，仍可使用音乐与文字。不会自动更换语音模型。点击消息下方的“REPLAY”可以重试合成或播放已缓存口播。

- Fish：到 [Fish Audio API Keys](https://fish.audio/app/api-keys/) 创建 Key，不需要再填写音色 ID。

## 音乐怎么接

不用申请网易云 API Key。项目在本机运行 `@neteasecloudmusicapienhanced/api` 社区接口，负责搜索和取得播放地址；它不是网易云官方开放 API。

先直接搜索一首歌测试。需要连接账号时，点击界面的网易云连接入口，用网易云音乐 App 扫码并确认。应用只在本机保存登录会话，不需要把账号密码写入 `.env`。

搜索到歌曲不等于可以完整播放。是否可播、是否只有试听，取决于歌曲版权与账号权限；程序会标记试听，不提供解锁或绕过会员限制。社区接口也可能随上游变化而失效。

## 日常使用

1. 在品味设置中写下喜欢的歌手、风格和不喜欢的类型。
2. 输入“给我三首适合专注工作的歌”等需求，等待歌曲卡片和主持串词。
3. Bob 先说完串词，新的一组歌随即开始播放；正在放的旧歌会淡出。关闭自动口播时直接开始播放。
4. 用播放器控制播放、暂停和切歌，或直接输入“暂停”“下一首”等简单指令。
5. 一组歌不会循环播放。最后一首快结束时，Bob 会准备收尾，并问你是顺着这个感觉继续还是换点别的，同时给出下一组候选。回复“好”“可以”“来吧”，或点消息下方的 PLAY ALL 即可接着听；也可以直接说想听什么。
6. 搜索结果可以直接播放或加入队列。浏览器如果阻止自动播放，点击播放按钮即可。
7. 播放时，时钟移到左侧，旁边显示封面和随进度滚动的歌词（有翻译时附在每行下面）。没有封面时显示点阵占位；纯音乐、暂无歌词或歌词取不到时，显示歌名、歌手和原因。试听片段按实际起点对齐歌词。
8. 输入框上方有快捷回复，会随状态变化；Bob 问要不要接着听时，第一个按钮就是“好，接着放”。等待时会显示选歌、曲库匹配、录口播三个步骤的进度。

收藏：未登录网易云时存在本机浏览器；登录后爱心和 FAV 直接使用你网易云的「我喜欢的音乐」（列表显示最近 100 首）。两边互不同步，退出登录后仍看到浏览器里原来的收藏。

AI 推荐的歌会到曲库里匹配：允许 “(2013 Remaster)” 之类的版本后缀和多位歌手写法，优先原版录音，避开 Live、伴奏、翻唱等版本（除非你点名要）。

## 本地数据与范围

| 位置 | 内容 |
| --- | --- |
| `.env` | 服务密钥与配置，已被 Git 忽略。 |
| `user/taste.md` | 你保存的音乐品味。 |
| `.data/state.db` | 聊天、播放记录、节目计划、队列和网易云登录会话。 |
| `.data/tts/` | Fish 主持口播 MP3 缓存；按内容、模型和音色区分复用。 |
| `.data/claude/` | 原 CLI 的历史工作目录；升级保留，新 API 模式不再创建或使用。 |
| `.data/music/` | 音乐服务工作目录与临时数据。 |

`.data/` 已被 Git 忽略，数据库和语音文件限制为当前用户访问。程序在本机运行，模型与语音请求仍会发送到各自配置的外部服务。

目前没有实现麦克风输入（按钮已移除）、天气、日历、定时节目、客厅音响或多设备同步。模型选曲会经过曲库匹配，但不保证每首推荐都有可播放音源。网络或额度错误可以稍后重试。
