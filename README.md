# Radio Bob

本机运行的个人 AI 电台：用一句话选歌，听 Bob 的中文串词，也可以搜索歌曲、管理待播队列并保存音乐偏好。

## 添加到熊猫小抽屉

在熊猫小抽屉的推荐列表选择 Radio Bob，或在「添加应用 › 有应用链接」粘贴本仓库链接。已有下载文件夹时，选择包含 `panda.json` 的根目录添加。本应用使用 `panda.json` v2，包含 Node 24 后台。

## 配置和费用

在平台配置表单填写自己的凭据：

- **DeepSeek API Key**（必填）：用于选歌和生成主持串词。代码中的环境变量名为 `ANTHROPIC_API_KEY`，这里仍填写 DeepSeek 的密钥。
- **Fish API Key**（选填）：用于主持语音。留空也能使用文字串词和音乐。

AI 与语音服务由各自提供方按用量收费，具体额度和价格以服务提供方为准。音乐可用性受音乐服务和账号权限影响。密钥由平台保存并只交给后台，不需要发给 AI，也不需要维护 `.env`。

## 使用

打开后输入想听的音乐或场景，生成一段节目；也可以直接搜索歌曲、调整队列。播放控制可暂停、继续和切歌。需要口播时填写 Fish 密钥并开启自动口播；失败时先看界面原因，必要时重试。

本机文件数据在应用的 `data/` 中。平台归属的应用删除时会一并删除其代码和数据；用户自己选择的文件夹会保留，平台配置与浏览器存储仍会清除。

## 用自己的 AI 修改

在窗口点「按你的想法改」，向自己的 AI 描述需求。修改后运行 `app reload` 或点「重新加载」；后台问题先用 `app logs` 查看日志。删除或清空数据前先确认，Git 只保存代码。
