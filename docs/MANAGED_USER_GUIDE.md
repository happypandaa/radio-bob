# Radio Bob 平台配置与试验说明

这是“Node 服务项目”的本机源码接入：在平台配置后，从平台打开唯一原生应用窗口，Node 由平台在后台启动，关闭应用窗口就停止。不要求普通用户安装 Node、运行命令或另开浏览器。当前仍不包含完整可分发包安装、备份、更新或迁移能力。

首次试验验证了实例初始化、本地后端、状态、人工队列/品味、正常停止和异常退出；此前还通过一次真实 DeepSeek 选曲、曲库匹配和浏览器音乐播放。那些是较早的诊断证据，不能替代当前原生应用窗口验收。后端不直接提供网页，平台负责受控原生窗口与本机连接，用户不需要取得端口或认证令牌。

## 在原实例更新应用说明

当前语音仅保留 Fish Audio，配置只保留下方两把密钥。先关闭 Radio，在平台详情通过“查看新版应用说明”或构建更新同步当前清单与网页资源，再保存配置并重新打开。源码变更不会直接覆盖已安装的运行副本。

平台应保留同一实例的配置、密钥与数据；更新不会自动启动 Radio。旧平台若没有应用说明更新入口，需要升级平台后再更新，无需删除实例重新登记。当前源码检查不能代替原生窗口中的实际验收。

## 从平台使用

1. 从平台“我的项目”接入这个源码目录，Radio 以 Node 类型图标显示，和网页类型卡片位于同一列表；从卡片打开页内带 tabs 的详情／配置弹窗，完成上述应用说明更新后，按下面各项说明填写。已有普通默认值通常不用改。
2. 保存配置。按用户最新选择，API 密钥存放在 Radio 自己的本机受管槽 `configuration/credentials/` 私有文件中，目录权限 `0700`、文件权限 `0600`。这是当前用户文件权限保护的明文，不是 macOS 钥匙串或系统加密库；界面仅显示“已设置”，不会读回显示。该槽不是源码目录或分享包，不要把密钥写进说明文件、Git 或截图。
3. 点击“打开应用”。必填不足时该入口仍可点击，先打开同一详情弹窗的配置 tab，提示缺项与获取方法，不把用户留在禁用按钮外。保存不会自动启动；配置完整后再明确打开，平台后台启动服务并显示原生窗口。
4. 再次打开只聚焦同一个窗口，节目与未保存内容不会因为重复点击而重置；不另开浏览器、终端或弹出第二个应用窗口。
5. 关闭 Radio 应用窗口要收尾它的全部受管 Node、普通子进程与连接。以后再打开时使用已保存配置和本机受管数据；其他应用和独立 Node 不受影响。无法确认清理时应保留异常状态，不能假称全部已停止。

保存配置、选中条目或重新打开平台本身都不会自动启动 Radio。运行中修改配置，明确“重启并应用配置”，或关闭 Radio 后再打开。按最新要求，平台管理主窗口 X 与菜单退出一样正常退出平台，关闭全部业务窗口并收尾全部受管 Node，不再仅隐藏托盘；用户独立启动的 Node 不会被终止。原生窗口流程的实际验证结果以平台当前交付记录为准。

## 应用需要哪些配置

`local-app.json` 是应用交给平台的说明文件：声明运行方式，以及需要用户提供哪些配置。它只包含用途、默认地址、默认模型和帮助链接，**不包含任何人的真实密钥**。密钥属于使用者自己的账号，不能写进说明文件后随应用分享。

只需填写两把密钥：DeepSeek API Key 必填，Fish API Key 可选。其余使用默认值。

| 设置 | 怎么填 | 不填的影响 |
| --- | --- | --- |
| DeepSeek API Key | 到 [DeepSeek API keys](https://platform.deepseek.com/api_keys) 创建自己的密钥。 | 必填，缺少时标准配置校验不允许启动。 |
| Fish API Key | 到 [Fish Audio API Keys](https://fish.audio/app/api-keys/) 创建自己的密钥。 | 可选，留空时仅使用文字串词和音乐。 |

后端默认使用 DeepSeek 的 `https://api.deepseek.com/anthropic` 接口和 `deepseek-flash` 模型；主持口播固定使用 Fish Audio 的 `s2.1-pro-free` 与默认音色，不需要填写地址、模型或音色 ID。名称带 `free` 不保证账号有可用额度或权限，实际调用以服务商响应为准。

较早离线验证只用人工值；早期真实 DeepSeek 试跑的凭据仅临时注入而不保存。当前平台改用 Radio 槽内的私有秘密文件，不读取、迁移或删除此前的 Keychain 条目，不能把早期记录当作当前存储方式。原有受管子进程还可直接启动来做无密钥的隔离生命周期测试，这不代表通过了 AI 版 Radio 的标准配置校验。

清单已写出每项中文用途、不填影响、获取步骤和官方帮助链接；平台按这些声明提供通用配置入口、普通值保存及本槽私有秘密文件绑定。保存成功只表示本机配置已保存，不代表服务商已接受密钥或账户有可用额度。不要用真实密钥修改清单；完整字段以 `local-app.json` 为准。

真实网易云登录暂时关闭。独立版把 Cookie 放在业务库，尚未完成独立私有凭据与归档隔离适配，不能把备份／分享当作已经过滤了所有凭据。

## 状态与停止

“后端就绪”只表示本地实例已初始化并能响应，不证明 AI、TTS、网易云登录或真实音乐播放成功。本地健康检查不请求外部服务。

关闭原生应用窗口或明确停止时，平台走同一停止流程：先停止新请求、结束事件流、等待在途业务结束再关闭数据库；控制通道断开也会停止。五秒内未完成收尾会异常退出，不能据此宣称数据已安全保存。出现异常终止时保留隔离目录供检查，不自动重放业务请求。

## 数据边界

平台注入的 `APP_DATA_DIR` 保存本试验数据库与品味，`APP_CACHE_DIR` 保存 Fish 口播 MP3 缓存，`APP_TEMP_DIR` 保存 SDK 临时状态。受管入口拒绝把这些目录指向原项目或互相重叠；原 `.env`、聊天、队列、品味和 Cookie 不迁移、不读取。

当前未交付完整安装、数据迁移、备份恢复、凭据复制、清理和更新流程；不要把试验目录替代真实项目。早期 Mac 浏览器诊断已验证匿名搜索、30 秒试听，以及一首约 75 秒完整音源的播放进度与暂停；歌曲权限因曲目而异。真实登录、Fish 口播、长期运行及当前原生窗口内的真实播放，需要按平台交付记录分别核对，不能由上述浏览器诊断推导通过。当前源码的自动化检查使用模拟服务，实际 Fish 账号权限、额度和音质仍需单独验证。
